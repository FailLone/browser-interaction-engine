# 抽样遍历器（Sampled Crawler）计划

分支：`claude/traversal-blockage-investigation`。起点 `f00fc35b`（旧插件修补，作为对照基线）。

## 背景与结论

2026-10-19 用 `https://www.okx.com/convert/usd-to-btc` 实测：

- 旧插件 240 秒只执行 12 个命令，782 条待办完成 6 条，模型 0 次调用。
- 大部分时间花在执行前证明（3756 次 SDK 调用，浏览器点击仅 4.8 秒）。
- 约 4 次点击后就离开入口页，在各页面的导航菜单里打转；同一列表/价格变化不断生成新待办。

原因是"穷尽 = 可证明地穷尽"的定义：任何不能证明等价的东西都成为永久义务，真实站点上永不收敛。

## 新目标

"穷尽"的含义改为：**像真实用户一样，在给定范围内把页面的各种状态尽量交互出来，让 UI 问题暴露**（类似 Crawljax）。

- 同类东西测一个或几个即可（列表项、同模板卡片）。
- 易变内容（价格、时间、百分比、计数）不构成新组件或新状态。
- 完成条件：范围内每个"状态 × 动作类别"至少执行 k 次，或预算用完。
- 大模型是插件：程序判断不了的疑问先问 JEV（便宜），JEV 拿不准再问 LLM；答案直接生效并缓存。
- 以后用"目标模式"代替穷尽：LLM 生成范围/路径/任务，JEV 判断相关性。

## 设计

新包 `packages/crawler`，只复用适配器的页面抓取（`BrowserEngine` 的 observation / actions / execute）和 `rules`，不经过旧插件的义务账本与证明链。

1. **状态归类**：URL 路径 + 打开的弹窗/浮层 + 可交互控件骨架（角色、类型、去数字后的名称）。价格等数字统一屏蔽。
2. **动作归类**：动作类别 = 状态无关的 (区域路径, 角色, kind, 去数字名称)；同一结构化列表中的项归为一类（`structuralItem` / `list`），每类抽样 k 次（默认列表 2 次，其它 1 次）。
3. **调度优先级**（高→低）：
   1. 当前打开的弹窗/浮层/菜单内部动作；
   2. 入口页正文动作；
   3. 本页内会改变状态的控件（tab、展开、hover 菜单）；
   4. 页头/导航菜单（全站一次，仍在本页）；
   5. 同站同范围的跳转（当前页没有页内动作后才发生）。
   离开范围的链接不执行。
4. **蒙层处理**：弹窗打开时只在弹窗内部选动作；若弹窗内没有可执行动作，先尝试关闭（关闭按钮 / Escape），而不是在被遮挡的背景上反复失败。点击被拦截的动作记为一次失败，不重试同一类。
5. **回退**：需要回到某状态时，从入口 URL 重放记录的动作路径；失败则放弃该状态剩余动作。
6. **安全策略**：一份允许操作 + 禁止项（登录、注册、交易、提交、外站、下载）。单层检查。
7. **规则 hook（可选，默认关闭）**：每进入新状态可运行检查。当前以遍历为主，不以发现问题为验收目标。
8. **模型插件（步骤 2）**：疑问队列，JEV→LLM，按材料哈希缓存，答案直接生效。

## 分步实施与验收

| 步骤 | 内容 | OKX 验收（240 秒） |
|---|---|---|
| 1 | 纯程序抽样遍历器 + 运行脚本 + 指标 | 只测入口页时 ≥70% 动作在入口 URL 上，宽范围时入口页的页内动作在任何跳转前完成；弹窗打开时先处理弹窗；同一列表最多执行 k 次；不同状态数可报告 |
| 2 | 模型判疑（JEV→LLM，缓存） | 模型实际被调用；待定控件被分类后可执行 |
| 3 | 目标模式（LLM 生成范围/任务，JEV 剪枝） | 给定目标时只在相关范围内探索 |

每步完成后在 `docs/experiments/sampled-crawler/` 记录实测结果；结果不达标时如实记录。
