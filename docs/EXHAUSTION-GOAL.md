# 穷尽能力与 OKX 完整验收

开始：2026-10-15；基线 `0166a74`；工作分支 `codex/okx-exploration`。本文件跟踪当前用户目标，不将“本轮改动通过”或“已知待办耗尽”当作目标完成。

用户目标：完成与穷尽有关的 roadmap 需求，并对 https://www.okx.com/convert/btc-to-usd 做真实测试直到确实可以穷尽。需要上游判断时，由 `gpt-5.6-sol` / `low` sub agent 独立模拟上游；必须展示列表由该 agent 选择跳过或抽样，以及跳转后不在目的页深入遍历。

## 完成口径

- 保留整页入口 A 的发现与执行范围，不能只验证换算器或几个已知按钮就宣称整页完成。
- 列表的样本/跳过、目的页不深入必须来自有材料和理由的上游决定；未选成员仍列为未执行。其他控件不能为消除阻塞而静默排除。
- 分开报告已执行、上游明确不测、等待判断、发现缺口、程序阻塞、环境条件以及预算停止。零 pending 或 finished 不足以证明完成。
- 每个获批操作由引擎实际执行并保留前后证据；每次离页记录来源、目的页门控、返回及回到 A 后继续工作的证据。界面返回不等同完整业务恢复。
- 真实站点的服务故障、登录/验证码、交易、不可逆服务器状态不得伪造为通过；保留证据并推进可独立完成的工作。
- 所有下列 roadmap 项需有当前实现和相应尺度的验收，不能用有限样本替代广泛能力的证明。尚无证据的项保持未完成。
