# 持续更新页面的遍历

`controls` 模式不要求页面达到视觉静止。实时展示仍写入原始观察、DOM 证据和截图；控件覆盖只比较与操作相关的投影。完整 `canonical` / UIState 和严格检查点继续保留数据变化，不以覆盖相同冒充业务状态相同。

## 通用判断依据

实现不含站点、域名、币种、控件名称或站点 CSS 特例。默认区分以下情形：

- 已有的纯展示、只读输入，以及没有受支持操作的图表容器，不进入可操作控件稳定性比较。Canvas 内部继续报告覆盖缺口，图表绘制变化不是已经测试了图表交互。
- 列表项优先使用显式记录键。缺少记录键时，使用该列表中唯一的有效 HTTP(S) 链接目标集合；链接集合相同的多项不能用此方法合并，退回原来的描述证据。行号、位置和可复用节点 ID 不作为业务记录键。链接改变时重新判定绑定。由链接集合推测的行绑定只在当前记录节点和当前控件实例内有效；它不能证明共享目标在历史上始终指向同一记录。
- 链接集合和描述文字使用相同的记录边界：嵌套列表、独立子面板和隐藏后代不参与父记录绑定。没有面板语义时，仍需展开入口、独立定位和超出父项边界的几何证据。子菜单切换结果不会反复产生新的父入口；父项自己的目标改变仍使绑定失效。
- 没有链接或声明键时，描述性记录键可排除被动的货币/百分比显示子树，前提是剩余描述包含文字且在同一列表中唯一。纯数字记录 ID、显式标签及交互控件不按此规则排除；投影后重名则退回完整描述，不合并业务对象。去掉价格的描述与推测链接绑定都标记 `identityScope: instance`，不能继承重建节点的历史覆盖或回放权限。当前节点曾消失后再出现也不自动恢复旧身份；显式记录键和未删减的完整描述仍使用原身份规则。
- 对有文字名称、目标明确的原生链接，被动的货币/百分比格式叶节点可直接作为展示读数；其他数字叶节点需在连续无引擎动作的采样中至少变化两次。格式明确的慢速读数也不必等待它先更新两次。链接必须仍有非数值名称；表单、下载、按钮/输入/选项等交互后代和改变的显式标签不适用。识别证据保存在 `control.liveContent`，原 `name` / `displayedText` 不改写。
- 链接目标或显式标签变化会重新学习；数值叶节点变成业务文字时撤销投影。动作开始时重置未确认候选的连续采样计数，避免把多次点击结果当作自主刷新。已经确认的展示资格只在原绑定和数值格式仍成立时延续。

这不是“任何持续变化都可忽略”的规则。没有可识别的语义或稳定绑定的自定义组件继续保守处理；不能仅通过更新频率推断业务无关性。

## 检查如何一致工作

身份签名和覆盖样本使用上述交互名称，列表键不包含报价。稳定性采样和执行前检查使用同一交互投影；完整原文仍用于证据和严格状态比较。`stateful` / `representative` 不自动启用实时文本投影。

执行前仍比较文档、URL、节点实例、记录键、控件结构、输入值、选择、约束、展开状态、操作依据和遮挡。声明的业务上下文每次重新读取，即使该节点已被识别为展示。非界面操作仍验证目标原始文本。

几何位置从全页面静止条件移到所选动作目标的执行前检查：其他控件移动不使当前目标失效，目标移动、替换或遮挡仍触发重新验证。实际执行继续使用原生定位及可操作性检查。`preflight(observation, action?)` 的第二参数可选，已有第三方驱动兼容。

对于原生 `fill` / `select` / `check`，可按 HTML 实际表单所有权验证依赖：包含通过 `form` 属性关联的外部字段、同表单其他交互控件、表单目标及目标几何位置。跨表单 ARIA 引用（含反向引用）、控制/拥有/描述关系等复合关联、嵌在列表记录内的表单、自定义操作、提交和无表单目标仍保留全局比较。文档、URL、历史、滚动位置、弹层和声明业务上下文始终校验；原生表单局部就绪不缩小启用的范围决策检查。原生表单范围约束的是 DOM 操作的校验范围，**不证明应用脚本的业务效果独立**；跨区域业务前提需由 context / contextRules 声明。

采样期间按每个表单计算一次依赖投影，再分别校验目标位置，避免每个字段重复扫描全表单。若只有部分原生字段达到稳定窗口，可生成完整证据并记录 `PARTIAL_INTERACTION_READY`；其他控件标记 `readiness.status: unstable`，其操作由 `interaction_unstable` 阻塞。无需等整个页面静止。后续观察确认稳定后可解除这种临时阻塞。

动作后只能用该动作自身的就绪条件确认结果：另一张表单稳定不能把当前动作的未知结果改记为成功。严格状态和检查点仍比较完整原始数据。逻辑表单绑定用于状态/覆盖比较，节点实例只用于实时校验，避免新文档的实例 ID 破坏可验证的历史恢复。

独占弹层的交互稳定性同时限定控件、列表和区域候选：背景候选以及混合父容器的整页成员变化不会让弹层内操作反复观察。完整观察仍保留背景变化；目标、弹层边界、弹层内区域绑定、文档、URL 和声明上下文继续校验。整页区域审批不因弹层局部就绪而获准，详见 [区域审阅](REGION-REVIEW.md)。

版本标识为 `observable-v3-live-v2`，控件抽样策略为 `browser-controls-live-v3`。旧观察不改写；身份裁决后的等价样本对账另见 [完成审计](EXPLORATION-AUDIT.md)，不等同于重新派发。

## 防止反复观察

会话持久保存 `observationFailures`：连续观察不完整，或执行前全局页面/上下文失效，均计数。达到 3 次后暂停，停止原因 `OBSERVATION_NO_PROGRESS`，并发出 `exploration.no_progress`。同一次新观察不重复计数。

在动作尚未派发的情况下，controls 模式可使用新观察重新验证同一待办；只重试读取与验证。已成功、失败或结果未知的动作不因此重放。恢复 DFS 或额外获取一张完整截图不清除执行前失效的计数；之后仍失效会立即再次暂停。一次成功操作清除计数；纯采集不完整的问题在完整观察确认后也可清除。

局部执行前失效单独保存在 `validationFailures`，按驱动和适配器共同确认的依赖范围计数；作用域没有证据、新观察不完整、目标或表单被重建时，退回全局保护，避免重建节点不断获得新的局部重试额度。每个范围累计 3 次后，该范围的未尝试待办标记 `action_dependencies_unstable`，其余可验证的待办继续执行。事件 `exploration.dependencies_invalidated` 保留范围、计数、观察引用及依据。新文案或样本不能绕过同一范围的失败预算；其他范围的成功也不清零。

剩下的工作均受局部依赖阻塞时，以 `ACTION_DEPENDENCIES_BLOCKED` 暂停，保留未覆盖项。反复观察或恢复 DFS 不会重新开启已耗尽的范围；处理变化原因后，显式执行该范围的新候选并成功观察其结果，才清除该范围计数。已经尝试且结果未知的旧动作不自动重放。

界面区分局部未就绪、采集不完整和连续无进展，不把反复点击“重新观察”或单纯延长等待作为解决方案。未执行和未知项始终保留覆盖缺口。

## 验收

`tests/live-content.test.ts` 使用独立 HTTP 页面和真实浏览器，不依赖外网、行情站点或应用专属配置。每 10 ms 更新的数值和 Canvas 从开始到结束不停止；两组不同名称、顺序的页面均应执行全部有限控件且每项只执行一次。

负向测试覆盖共享链接不能混同记录、列表重排与节点复用、按钮/输入/显式标签的持续变化、声明业务上下文、严格状态模式、无进展暂停及恢复、目标移动与遮挡、已识别读数变成业务文字。原观察生命周期测试继续验证未知动作不重放以及采集故障解除后恢复。

2026-10-15 的[真实页面验收](experiments/live-prices-acceptance-2026-10-15/README.md)完成了分类、筛选、搜索、详情图表周期和返回路径验证。四次没有引擎操作介入的采样中，原文与原始状态均改变，交互投影保持一致，随后两次分类操作成功。审阅辅助 DFS 继续到 83 次操作后仍有页面返回缺口；该结果不代表整页无人干预遍历完成。原始行情、图表内部交互缺口和严格恢复的 UNVERIFIED 均保留。

## 不能从 DOM 推断的情况

如果应用复用同一个节点，所有可见名称、链接、记录键和操作条件都不变，仅把已排除的展示价格替换成另一个业务对象的价格，通用观察不能证明对象已切换。此类应用需要显式记录键或业务上下文，不能靠更长等待解决。这里承诺的是避免跨实例误继承，而不是识别不可观察的业务身份。

没有已验证的返回路径，或此前执行了业务效果未知的操作时，页面返回仍需已有的用途/恢复契约。局部稳定不授予返回权限，也不清除 dirty 状态；不能以“URL 回来了”代替业务恢复证明。
