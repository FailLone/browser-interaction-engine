# OKX 自主探索：恢复实测与本地开销修复

目标仍是探索 `https://www.okx.com/convert/btc-to-usd` 的完整当前页面交互范围，包含后续出现的菜单和弹层。本记录不是穷尽验收通过。任务 `257f9b5f-79bf-4954-b8cc-11d1a379645d` 沿用原始全页计划、历史证据及累计预算，没有创建一个更小的任务替代它。

## 已确认的开销与修复

1. **观察期间重复重建待办。** 真实重载发生了 34 条分组失效，SDK 原先逐事件重建整份 intervention 材料。现在一次 capture 中的失效、操作完成和审阅 hook 合并到 capture 结束后同步，嵌套 capture 也合并；异常退出会释放合并状态并同步已提交的事实。原始事件全部保留，公开查询仍即时计算，执行校验不依赖通知时机。回归覆盖 12 组同时失效、观察成功及失败，重建均为 1 次，原批准全部失效。
2. **读取证据时扫描永久历史。** 真实库已有 1353 份保留清单，均没有 TTL。8 秒 CPU 采样中，4619 个采样点中的 1311 个包含过期检查调用。现在只索引具有 TTL 或有限期固定记录的清单 ID；单份证据读取仅核对所属清单。索引启动时重建，每次清单写入更新；清单内容、当前观察、开放范围和固定保护仍实时读取，不缓存授权。测试覆盖永久历史不被反复扫描、重启、重启后新增有限期固定、固定到期及实际证据删除。
3. **控件分类历史逐控件重复读取。** 构建一份控件用途材料时，统一读取一次分类历史并按当前观察计算非交互目标；候选过滤和批量分类也共享本次调用的记录。没有跨观察缓存。30 个控件的回归验证只读取一次，撤销一个分类后立即重新待审阅，再改变另一个目标后待审阅增加到两个。

上述变更位于 SDK 和证据生命周期层。插件继续负责 JEV/LLM、任务范围、探索顺序和预算，没有站点专用规则。

加载优化后再次采样 8 秒，5936 个采样点中仅 1 个包含证据过期检查。两次采样覆盖的具体工作不同，不能直接换算总吞吐提升；它确认了永久证据扫描不再占据主要采样。此时剩余主要开销包括审阅缺口核对所触发的完整审计快照和历史覆盖材料读取，后续仍需测量并减少重复构建。

## 真实运行记录

恢复前是 12 轮、109 次动作、2283 次模型请求，累计活动时间 22,206,939 ms。按照用户允许跳过不支持内容的指令，通过公开任务接口登记 `UNSUPPORTED_CANVAS` 为已接受的未测项；它不计执行覆盖。增加 3 轮、300 次动作、60 分钟和 600 次模型请求额度，原累计用量不清零。

第一次恢复在页面重新接入阶段消耗约 78 秒，尚未调用新模型。合并重建修复后继续真实运行，并通过一次有记录的暂停与重启加载证据和分类优化。最终版本从恢复请求到 `round.reattached` 约 21 秒。两次的页面和审阅状态不同，这些数字用于定位实际等待，不是同条件性能基准。

目前新增动作包括重新接入后的地区提示弹层关闭。这属于真实成功动作，但不是新的页面分支覆盖。模型用于区域、控件分类、风险、身份和下一动作选择，JEV 为主要服务；无法确认分类时转交 LLM。具体截止时刻、调用数及未完成统计见同目录 `progress.json`。

历史未知导航 `a7e1dcc5-1692-4391-b573-ef3bd0c68324` 仍为 unknown。新会话或新的 Close 成功都不能证明这次导航成功，也没有重放它。页面其余未完成范围继续保留，任务仍未证明穷尽。

性能采样结束后，关闭 Node inspector 的诊断表达式使用了该上下文不支持的动态导入，导致开发服务以 `ERR_VM_DYNAMIC_IMPORT_CALLBACK_MISSING` 退出。这是本次诊断操作造成的中断，不是网站或模型故障。服务随后重启，旧任务按 `process_restarted` 暂停；111 次动作、2450 次模型请求及累计时间保留，`pendingDispatch` 为空，未返回的模型请求变为过期。通过公开接口继续原任务，未清除任何旧未知结果。恢复检查见 `progress.json` 的 `diagnosticRecovery`。

## 后续效率工作

- 冷重启会创建新的浏览器文档，旧身份和审阅不能继承授权。应减少为了加载修复而产生的重启；如果要保存浏览器会话，必须另外定义连接生命周期和恢复验证契约。
- 若本地重复计算消除后仍主要等待模型，可在插件中加入有界并发：只并行没有依赖的判断，已明确的可执行分支先运行。结果必须绑定任务版本、来源观察和审阅条件，过期结果只留审计。当前未实现此调度，不声称已经并发，也未引入新框架。
- 操作数或模型请求数增加不是穷尽证明；继续以新增分支证据和未完成范围减少来衡量进展。
