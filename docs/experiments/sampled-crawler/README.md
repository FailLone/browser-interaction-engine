# 抽样遍历器实测记录

计划见 [SAMPLED-CRAWLER-PLAN.md](../../SAMPLED-CRAWLER-PLAN.md)。

## 步骤 1：纯程序版（2026-10-19）

命令（无模型，无登录）：

```sh
pnpm exec tsx --conditions=development scripts/sampled-crawl.ts OUT https://www.okx.com/convert/usd-to-btc 240000 \
  '^/(?:[a-z]{2}(?:-[a-z]+)?/)?(?:convert(?:/[^/]+)?|markets(?:/[^?#]*)?|price(?:/[^?#]*)?)/?$'
```

范围：入口页加同站 convert / markets / price 页面。结果 `okx-step1-summary.json`，事件 `okx-step1-events.jsonl.gz`。

| 指标 | 旧插件（同入口，240 秒） | 抽样遍历器 |
|---|---|---|
| 执行动作 | 12 | 72（164 秒后自行结束：范围内抽样已完成） |
| 不同 UI 状态 | 不适用 | 41 |
| 入口页上的动作 | 约 2 | 32 |
| 弹窗/浮层内动作 | 2 | 14（modal、listbox、popover、dialog） |
| 离开 okx.com | 有（OKX Wallet、外站） | 0（站外导航在发出前被拦截） |
| 同一列表类最多执行 | 不适用 | 1 次；28 个列表类共 368 个成员，只执行 13 次 |
| 模型调用 | 0 | 0（步骤 2 才接入） |

观察：

- 第一个动作就是地区限制弹窗内部，没有在被蒙层遮住的背景上浪费时间。
- 交易对、语言、FAQ 等列表都按类抽样，没有逐项点击。
- 页面模板抽样：`/convert/*` 最多进 2 个具体页，每个非入口页最多 20 个动作。
- 4 次失败中 3 次是分享/外链被拦截（按设计记为失败并不再重试），1 次是视觉隐藏的 "Skip to main content" 点击超时。
- 规则检查本次未发现问题。早期版本的"中心被遮挡"检查误报过多，已删除；剩下图片加载失败和文字截断两项，在本地夹具上验证会报出。

未达成：计划中"≥70% 动作在入口 URL"本次为 44%（32/72），因为范围允许进入同站价格页。只测入口页时（不传第四个参数）100% 在入口页。

### 步骤 1 补充：只测入口页

不传范围参数（只允许入口页），同一入口 240 秒：49 个动作全部在入口页（100%，达到 ≥70% 的标准），72 秒后自行结束。数据见 `okx-step2-summary.json`（该次同时开启了模型判疑）。

方向调整（2026-10-19，用户要求）：不再把"检测出 UI 问题"作为目标，先以遍历为主。规则检查改为可选（`checks` 选项，默认关闭），验收只看遍历指标。

## 步骤 2：模型判疑（JEV→LLM）

程序判断不了的两类问题交给模型，答案直接生效并缓存：

- **弱控件是否可交互**：只有指针样式、tabindex、框架事件属性等弱线索的元素。同一状态下的问题合并成一次 JEV checklist 调用；JEV 概率落在 0.2–0.8 之间的才逐个问 LLM。回答"是"后，这一类控件就进入候选。
- **无结构变化的动作是否改变了内容**：比如图表时间范围切换。页面文字有变化时才问。

OKX 实测（只测入口页，240 秒，真实 `typesafe/jev-1.13` 与 `deepseek/deepseek-v4.1-flash`）：

| 指标 | 无模型（步骤 1 同配置） | 有模型 |
|---|---|---|
| 动作 | 约 32 | 49 |
| 模型调用 | 0 | JEV 7 次、LLM 24 次 |
| 被确认可交互的弱控件类 | 0 | 19（页头 Trade/Learn/More 菜单、Chat with us、指标说明等） |
| 首个动作时间 | 约 2 秒 | 5 秒（等第一批 JEV） |

问题：JEV 对这类问题给出的概率大多在 0.4–0.75，落在不确定区间，所以大部分仍由 LLM 决定，LLM 调用偏多。阈值和问题措辞需要再调。

## 步骤 3：目标模式

LLM 根据目标和入口页可见控件生成 `allowedPaths / focus / tasks`；JEV 每个状态一次 checklist 调用，给候选动作类打相关性分数，低于 0.3 的剪掉，其余按相关性排序（弹窗仍然优先）。

OKX 实测，目标"测试兑换计算器：切换法币和加密货币、查看汇率图表的不同时间范围"（180 秒）：

- 计划出的范围：`^/convert/[a-z0-9]+-to-[a-z0-9]+$`；重点为金额输入、两个币种选择器、图表时间范围等。
- JEV 6 次调用，剪掉 45 类无关动作（页头菜单、FAQ、语言切换等）。
- 执行的 12 个动作：先处理地区弹窗，然后图表 1h、USD 选择器、BTC 选择器、进入另一个兑换对页面并打开其币种选择器。50 秒后范围内的相关动作抽样完毕，自行结束。

限制：遍历器还不会填写输入框，所以"输入金额"这类任务没有执行；图表的 1h/1W/1M 被识别为同一列表类，只点了一个。
