# 持久控件审阅与真实列表抽样

本次为 `work/exhaustion-goal/run-02` 的局部验收。上游由 `gpt-5.6-sol` / low 独立审阅材料和截图，提交五批决定；引擎通过正式 `reviewControls` 保存用途证据并派发操作。原始工作台数据和 SQLite 留存在该工作目录，仓库保留精简观察、完整尝试、审阅记录及独立判断。

实际执行共五次，全部有前后观察：

| 次序 | 操作 | 结果证据 |
| --- | --- | --- |
| 1 | A 页 Close | 提示框消失，底层控件恢复可点击 |
| 2 | 自定义 BTC 入口 | 上游依据当前目标及截图批准单次探测；真实出现 Search、币种行和虚拟滚动容器 |
| 3 | 1INCH 单样本 | 上游决定只选一个非当前币种；URL、文档、标题和页面内容实际变为 1INCH/USD |
| 4 | B 页 Close | 上游将目的页范围设为 skip，只批准关闭阻挡返回的提示 |
| 5 | 原生 history 返回 | 引擎自动调度返回 BTC/USD；回到新文档，全部四条控件审阅已失效 |

列表用途审阅改变了操作依据和分组 revision，上游重新读取材料，将 revision 1 的旧成员 key 替换为 revision 2 的当前 1INCH key。调用适配只将上游描述字段 `sampleKeys` 改名为 API 的 `memberKeys`，未改成员选择。列表和目的页的未执行内容保留为未测。上游分别确认了真实展开、真实跳转和真实返回，不能由 dispatch succeeded 单独推导这些效果。

前四次操作是显式 execute；最后一次返回由 DFS 调度。返回操作开始后调用方请求暂停，等待当前操作完成，因此没有在返回 A 后未经新审阅就操作提示偏好。B 上只有 Close 和 history，没有目的页业务操作。返回 A 后提示再次出现；本次没有执行“7 天内不再提示”。

这不是整页穷尽证明。最终已记录的 427 个历史 action case 中：成功 5、按策略排除 211、待执行 33、阻塞 174、旧意图退役 4；未尝试 422。未知控件和发现缺口仍不属于完整发现证明，`discoveryComplete` 为 false。其他菜单、搜索、虚拟列表滚动、更多页面导航及恢复仍待验收。

运行源码以 [runtime-source.json](runtime-source.json) 的哈希为准：基线为 `a992de3`，加载本轮未提交的首版控件审阅。进程启动后又修正了请求事件发布时机、迟到现场校验写入及只读行情标签造成的全局前置校验循环；这三项修正由当前回归验证，不能声称旧运行进程已经加载它们。返回后的会话已暂停，随后保存证据并关闭本轮工作台；未通过重启消除页面阻塞。
