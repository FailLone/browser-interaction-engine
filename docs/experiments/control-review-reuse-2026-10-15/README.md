# 普通控件用途的显式条件复用

日期：2026-10-15。分支 `codex/control-review-reuse`，产品实现 `02317b6`。

## 实现与边界

普通控件审阅可显式声明 `reuse: {binding: "same-url-context", businessScope}`。引擎在新文档或节点重建后提供 `reuseCandidates`，上层通过 `reuseControlReviews` 接受，生成新的当前实例审阅，保存来源链并发布持久事件。旧批准不会自动恢复。

匹配准确 URL、全部已知声明上下文、当前目标、操作依据、输入约束、表单端点及完整有界祖先证据；同名不同链接、不同结构及多个当前匹配目标均不能复用。每次派发仍验证当前事实，来源撤销会使派生批准失效。新记录不继承 replay 权限、区域/页面决定、身份或检查结果。

首版覆盖普通控件用途，包括返回 A 后引用已有判断；列表、活动弹层和原生提交使用各自协议，不支持跨 URL 或跨会话。业务依赖需要由上层提供 context，结构一致不能证明未声明的服务端状态。详见[协议](../../CONTROL-REVIEW.md#普通控件的显式用途复用)。E11 仍为部分完成，区域深度决定、依赖驱动结果复用及必要证据优化尚未实现。
