## 实测结果

| 环节 | 实际结果 |
| --- | --- |
| 程序先处理已支持操作 | `continueExploration` 重新观察后启动 DFS，原生 Close 关闭地区提示；随后因区域待审暂停，动作数 1 |
| 上游限定范围 | 通过 `respondToIntervention` 划分金额字段和六个图表周期；其他区域及页面滚动保持待决 |
| 上游提供有效样本 | 金额是原生 `type=text`，默认候选值为 `example`。通过原有 `reviewControls` 明确本轮样本为 `2`，不把原生填入能力当作业务样本有效性 |
| 暂缓独立范围 | 图表区域选择 defer，金额只选 `2`；验证后 DFS 填入 `2`，USD 展示从 `82,110.3` 变为 `164,220.6`，图表仍选中 `24h`，累计动作数 2 |
| 拒绝迟到答复 | 生成图表答案后重新观察，再提交旧答案；即使组 revision 仍为 2，也返回 `STALE_INTERVENTION`。决定记录及动作记录均未增加 |
| 新决定后续测 | 读取新材料，为图表区域及重叠的相似列表分别选择当前 `1h` 成员；继续验证通过，DFS 实际点击 `1h`，其选中态改变且金额保持 `2`，累计动作数 3 |
| 重复请求 | 原样重发图表继续请求，返回同一继续记录；观察、会话及 3 条动作记录保持不变 |
| 记录与通知 | 持久记录含 6 条统一答复（5 applied、1 rejected）、3 条继续验证；事件含 24 次材料更新、6 次答复及 3 次继续结果，记录 ID 一一对应 |

所有页面操作均由引擎执行，只有 Close、金额 `2`、`1h` 三次；10 次观察保持同一文档和原 URL。范围、用途及样本由本次 Codex 在引擎队列外根据当前 DOM、截图和材料作出，来源为 `codex-bounded-okx-review`，没有调用独立审阅 agent，也未继承其他真实会话的批准。另有一次独立 agent-browser 只读预检，不计入引擎覆盖和上述证据。

本轮金额样本使用原有领域接口提交：该原生输入已支持 fill，统一待办没有为它产生未知用途事项。区域和深度决定使用统一答复接口。图表同时受区域与相似列表约束，批准其中之一不会绕过另一项。

初始完整观察为不稳定；第一次继续请求产生的新观察已稳定，验证正常通过。后续两次继续也均产生新观察并通过校验，没有放宽稳定性或设置虚假的恢复证明。

## 保留的限制

最终整体仍为 `blocked / exhaustive:false`，暂停原因为 `REGION_REVIEW_REQUIRED`。198 个当前控件未划分；统一材料保留 59 项：56 项等待决定、2 项阻塞、1 项暂缓。阻塞分别为发现/证据不完整和一个不可达输入，仍包含结构扫描截断、Canvas 与未知事件入口等限制。已记录操作审计为：3 成功、6 策略排除、192 待决、3 阻塞、1 退役；这些是历史 action case，不能与当前控件或事项数量直接相加。

五个未选周期没有执行。它们以 `list_member_not_selected` 保留为 deferred，目前归入较笼统的 recovery 类，且该汇总项只提供 observe 入口；原探索组及其决定接口仍可查询和使用。这是后续可改善的交接表达与入口问题，没有阻止本次指定样本继续。金额样本仍需上游结合用途提供。

本轮未验证跨页返回、业务状态恢复、未知执行结果恢复、进程重启、SSE 消费者断线续接或整页穷尽；没有发生 recovery 尝试。它证明当前两个独立范围能够交接和续测，不能代替这些场景的验收。服务器重置、环境隔离和更多适配继续开放。本轮没有新增产品修复，也没有重新运行全量产品回归。
