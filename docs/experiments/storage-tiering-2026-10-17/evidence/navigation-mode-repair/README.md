1. **导航模式引用可以独立于控件执行身份得到验证。** `50a7e561fdbb82937c6c92f9a85d2248d7d11890`。历史可见菜单因列表捕获获得 instance 身份，当前隐藏菜单没有该身份；旧条件因此无法对应。现在完整、唯一、非 instance owner 下的导航 disclosure 可以使用独立结构引用。它要求命名导航上下文、每层导航记录的独立原生链接、捕获时解析的完整目的地和完整竞争库存；缺证、多链接竞争、业务记录、checkbox、对称项继续拒绝。owner 的标题来自唯一直属 disclosure 自身，不截取聚合文字。模式值仍逐项保留。

2. **有成功动作的历史列表，不一定是到达检查点的有效路径。** core 补丁与本记录同时提交。A/B 回归暴露：路径只记录 Run-A，随后外部切换 B 并创建检查点；回到 A 后重放 Run-A 无法恢复 B。现在只对不超过 16 步的路径作有界反证检查：所有历史结果均明确不同，才跳过动作后缀。中间结果等价或未知时保留既有提前到达行为。

   入口自身也可能是零步前缀。只有沿最多 16 个 visit 查到真实 initial 根或成功 entry/reset 回执，并确认入口也不同，才提前拒绝整条恢复。入口等价或缺证时保留入口重开和实时验证；未到达时不再执行已证明无效的后缀。待测目标仍保留，不改成功或覆盖。
