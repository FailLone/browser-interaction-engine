下一补丁候选：覆盖核对只按证明实际依赖的 observation ID 读取历史事实，限制一次查询同时持有的完整观察；完整历史报告仍保留全量路径。必须先证明数组旧路径、retained 回执、A/B 条件、unknown、缺证、别名及自定义适配器语义不退化。不可把不可得材料等同于无待测项，不可缓存恢复或执行许可。若按需访问改变公开覆盖接口、回调或一致性契约，则先补全明确的适用契约，不能把纯函数输出相等当作全部行为等价。

当前仅完成定位，未实施上述产品改造，未再运行真实浏览器窗口。

两份独立只读审查指出：旧数组路径的同 session 过滤、同 ID 最后项优先及索引构造顺序应保留；新路径不能绕过 `coverageMaterial` 覆写，不能把历史 store 读取换成公开 `observation` 覆写。`detached` 和 `recordRevision` 本身都不证明自定义 get/list 等价或回调纯读。按需路径需要明确的一致性与不可变事实契约，不满足的组合保留旧路径；版本变化不能吞成空结果或重跑有副作用回调。完整审计仍检查全部历史，按需查询不再触碰无关腐坏材料属于需说明的边界。

最小检查为数组/按需完整 proof 映射对照（复用现有 A/B、alias、unknown、缺失 after、portable 冲突、retained 正例），超过缓存容量后末尾合法命中、同索引前条拒绝后条成功，以及核心覆写/异常传播/下一查询重新读取。只有这些检查和相同材料输出核对通过，才运行一次 240 秒真实闭环窗口。
