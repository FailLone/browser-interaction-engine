首个终态 cursor 样本只需约 141 ms，因为它绕过原长扫描；该负样本保留。真实第七窗的严格恢复依旧因路径无重放许可被拒绝，不能把此次计算优化当作恢复成功率提升。主要剩余成本仍是重复读取历史观察；审阅批次后的新鲜度采集另列后续。
