# Lifecycle evidence

The diagnostic scripts are the exact programs used against the full private frozen-6 copy recorded in `copy-manifest.json`. Their absolute paths deliberately show the actual source and copy used. To repeat them elsewhere, use source commit `f6d7b9e2b427b5edf1fad359ecf8cc5a3df8ffcf`, create a **complete new private copy** of `.data/okx-storage-acceptance-20261017-v1-frozen-6`, and replace the repository and private-copy base literals in private copies of these scripts. Never replace the base with the original or frozen evidence directory: `SqliteStore` construction may initialize metadata in its supplied directory.

`inspect-reuse.mjs` consumes decoded `decisions-all.json` and `decisions-selected.json` from the copied plugin decisions table; selected decisions are those referenced by this run's `provider.requested` metric IDs. The retained decision JSON contains the full material. The smaller `decisions-summary.json` is the original diagnostic index, not a replacement for those inputs. The independent `../review-cost-tools/extract.py` provides a more portable full-copy/decision reconstruction and the independently generated `../review-cost-diagnosis.json` corroborates these region/classification counts.

Run the programs with Node24 and the source workspace's existing `tsx` loader/development condition in this order: `inspect-reuse.mjs`, `inspect-region-differences.mjs`, `inspect-mode-gaps.mjs`. Programs only read copied persisted engine facts and invoke pure conditions/reuse queries; no browser, provider or service is created. `source-hashes.json` records that each inspected source file equalled the baseline at diagnosis time. `mode-gaps.json` is the exact retained selector/branch analysis; its labels are evidence, not identity proof.

`completion-regression/baseline-8-manifest.json` records the isolated baseline archive, its full Git tree, private workspace links, test/runtime hashes before and after, command and exit code. Shared third-party dependencies are read-only; all 32 workspace links point inside that private archive. There is no build or install step. `baseline-8.log` preserves the five expected failures. The working-tree eight- and ten-test logs are explicitly separate and must not be attributed to the baseline. `working-tree-transient-syntax-error.log` records an intermediate concurrent source edit which failed before collecting tests; it is not a behavioral test result.

Final integration testing is owned by the root task. No original raw metrics, task records, or frozen database were changed by this diagnosis.
