## 已确认的通用缺陷

1. **行内字段被误判为记录集合。** Apply 后三个连续观察的可操作投影相同，但区域和结构列表绑定因价格单元格的 `stableKey` / `recordKey` 改变。结构扫描把继承 pointer 的 `td` 推成新的点击候选，并把价格当记录名。见 [观察差异](reentry-diff.json)。
2. **下拉滚动容器在语义列表之外。** 列表拥有选项，外层 viewport 拥有滚动条；旧边界只包住 listbox，滚动因此被 outside_active_boundary 阻塞。通用夹具复现了这个关系；已经提交在 `main@84e4cc4` 的 popup-relations 能找到包含 viewport 的浮动 panel，见 [结构核查](popup-scroll-audit.json)。这一能力由基线任务整合，本分支不重复实现。

针对第 1 项，`c7580c6` 使原生 `tr` / ARIA `row` 不再作为推测记录集合的 owner；明确的单元格操作、行记录本身以及嵌套集合仍各自采集。修复前两个真实浏览器夹具均在报价变化后的独立按钮执行中报 STALE_OBSERVATION，另一个夹具误把横向字段操作分组。修复后新增三项通过，记录名称真正改变仍拒绝旧观察。该修复不包含域名、行情名称或站点控件条件。

本轮冻结版本先前完整回归为 68 文件 / 496 项通过。行字段修复新增 3 项通过，相关动态内容、结构列表和弹层的其余 56 项通过，typecheck 通过。此处不把这些回归等同于真实页面范围验收通过；仍需整合基线浮层能力后重新冻结独立验收。
