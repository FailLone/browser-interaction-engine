A native link with no source fragment may finish navigation when a bounded native event trace proves an exact initial document commit and later same-document fragment additions on the same main frame and loader, with unchanged path/query and an exact observed final URL. This does not verify that later view. An explicitly requested fragment cannot be discarded. Missing/truncated/wrong-frame/wrong-loader traces, a changed path/query or an unrelated destination fail. This is not a workspaceId blacklist: no fragment names are interpreted. At most eight native events of 8192 URL characters are retained per actual dispatch.
