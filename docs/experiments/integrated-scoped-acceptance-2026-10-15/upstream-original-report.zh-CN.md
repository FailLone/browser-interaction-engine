# 独立上游 LLM 有限范围验收报告

结论：**通过，但保留业务效果证据限制**。本轮只验收 OKX 行情页的 Filters 入口、筛选浮层、两个连续价格输入、两个有限选项列表以及 Reset、Apply、关闭操作。该固定范围内的交互均可通过项目公共 API 完成。

本轮创建会话 `cc6fc11c-978a-41e6-a91b-5d7dff184e18`。自动账本记录 49 次实际 ActionAttempt，49 次成功，0 次失败，0 次动作级阻断；会话累计 `399797 ms`，远低于 45 分钟上限，动作数远低于 300 次上限。结束时会话已停止，共享 HTTP 服务保持运行。

有限列表按本轮观察全部验证：24h change 的 12 个选项均实际选中成功，Market cap 的 5 个选项均实际选中成功。较低位置的 24h change 选项通过项目暴露的滚动动作到达，没有直接操作浏览器。两个无名称 combobox 依据浮层中的相对位置和相邻标签分别完成身份消歧。

连续输入采用 `Min=1`、`Max=1000` 作为有依据的代表样本。价格区间是连续域，因此本轮不声称穷尽数值空间或组合空间。Reset 成功后，后续观察确认两个价格框和两个选择框均为空。再次填入代表值并执行 Apply 后，操作成功且浮层关闭；重新进入浮层时观察到 `Min=1`、`Max=1000` 仍然保留。显式关闭操作成功，最终观察 `dde89298-c8f0-4567-b060-76b1a727c245` 中浮层已消失。

Apply 的业务效果只按证据陈述：浮层关闭且输入在重进时保留。Apply 后可见表格里仍出现价格低于 1 的 DEX 行，因此无法证明该价格区间对所有可见类别统一生效；本报告不把动作成功误写为全表业务过滤已经成立。

调用层与动作层已分开统计。停止会话前自动账本有 168 个 HTTP 请求，其中 49 个 execute 请求。唯一非 2xx 响应是一次 `409 INVALID_REGION_REVIEW`：首次区域复核把已识别的边界退出控件与区域正文重叠提交，程序在动作派发前拒绝，未创建 ActionAttempt；移除退出控件后复核成功。此外有两次本地 curl 因未设置 URL 而在发出 HTTP 前失败，以及一次本地 jq 格式化错误；这些都不是项目动作失败。

项目生成的全页面 completion audit 为 blocked，因为它同时统计了大量固定范围外的行情行、导航、页脚、canvas 等控件。本轮的裁决仅针对合同固定范围，不能把全页面 pending 项算作本轮遗漏。

结束核查确认 HEAD 仍为 `a512747e30b24a009b193db8798b0225f103b9cd`，tracked 工作树干净；`freeze.json` 中 514 个 tracked 文件的 SHA-256 全部一致。验收过程中未修改源码、配置或依赖。
