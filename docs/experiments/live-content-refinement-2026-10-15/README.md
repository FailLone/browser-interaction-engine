# 动态内容、弱身份和局部依赖验收

分支 `fix/live-content-exploration` 已接到另一任务 `codex/okx-exploration` 的 `48ad958`，保留统一范围审阅和批量决策。此前实时内容修改一并迁移；开发及整合均在独立工作树，未修改 main。

## 本轮行为

- 推测链接集合、去掉价格后的行描述只绑定当前记录/控件实例；重建、观察到消失再出现时，不继承历史覆盖。明确记录键仍能跨重建识别。旧动作没有因此获得回放权限。
- 原生表单字段按实际依赖校验，包含表单外关联字段和目标位置；跨表单引用、复合关联、提交、自定义操作和无法界定的范围继续全局检查。上下文、文档、历史、滚动和交互边界始终保留检查。
- 一张表单持续刷新时，另一张已就绪表单能继续；局部失效按范围累计，3 次后暂缓该范围，其他范围成功或重复观察不会清零。只有该范围成功执行并完成自身观察才确认恢复。目标或表单重建失去连续性时使用全局预算，不能通过换节点无限重试。
- 另一范围稳定不能把当前动作的未知结果记成成功。界面给出局部阻塞和全局暂停的区别，未执行、未知结果仍是覆盖缺口。
- 采样按表单复用依赖投影，避免每个字段重复扫描全表单；尚未实现 DOM 增量采集。

规则和已知边界见 [LIVE-CONTENT.md](../../LIVE-CONTENT.md)。生产代码与新增 fixture 没有域名、币种、真实控件名称或站点样式特例。

## 独立回归

`tests/live-content.test.ts` 使用独立 HTTP 页面和真实 Chromium。包含不停更新的数值与 Canvas、弱记录重建、显式记录键、原生字段依赖、外部关联字段、目标移动、跨表单引用和反向引用、未知动作结果、全局上下文/弹层、局部暂停与恢复、持续重建不能绕过预算等。

另外在 core 验证弱身份的消失/重用，并验证界面提示。完整回归还覆盖导航返回、严格检查点、用途审阅与批量范围决策。

第一次整合全量运行：55 文件、355 项，其中 354 通过，1 项暴露旧调用方期待 `STALE_OBSERVATION`，新局部路径却返回另一错误码。已保留原有错误码并通过相关 58 项重跑；随后新增的防重建和反向引用保护纳入最终全量复验。最终结果见下方验证记录。
