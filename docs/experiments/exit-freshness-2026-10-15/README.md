上游仍由 `gpt-5.6-sol` / low 独立读取当前材料和截图；真实操作均经引擎派发。初次展开 Spot 时截图仍在加载，上游拒绝将页脚的六行列表当作顶部菜单证据，只要求重新观察，没有重复点击。加载完成后确认顶部六行属于同一市场导航范围，选择 BTC/USDT 单样本。先 defer 并保存用途审阅，再依据更新后的 revision 3 和成员键提交 sample；其余五行无尝试记录，未执行、未覆盖。

实际导航到 BTC/USDT 交易页 B 后，上游对当前 page 范围明确 skip。B 的整页 `stable:false`，当前弹层稳定，完整动态行情和非关键采集缺口仍保留。Close 审阅及执行成功，后续观察确认边界消失。随后启动默认 DFS，引擎通过已观察的 GET 历史条目返回入口 A；在返回动作开始后请求暂停，等待它完成，避免未审阅的新 A 操作随即执行。B 只执行 Close 和 history，没有业务深入。

返回后 A 的 URL、上下文和新文档均已验证。新文档没有继承旧控件批准；上游重新审阅并关闭 A 的地区提示。该结果表示真实页面位置返回，不表示恢复了原菜单、字段、行情或服务器业务状态，也不证明整页穷尽。
