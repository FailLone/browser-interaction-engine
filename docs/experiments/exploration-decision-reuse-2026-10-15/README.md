日期：2026-10-15。分支 `codex/exploration-decision-reuse`，引擎实现及 OKX 冻结版本 `2768807`。

## 本轮交付

程序比较当前证据、映射操作和校验目标；无法确定时输出原因、现场材料及下一步处理路径，等待上游；上游决定后可恢复 DFS。此次补齐的是已确认区域跨文档返回后的深度决定复用，仍由人或 LLM 决定适用范围和是否接受。

- 一次 all/sample/defer/skip 不自动授权复用；上游另行注册适用范围。
- 引擎输出完整匹配条件、原操作与当前操作映射。上游显式接受后生成新的当前决定，sample 不照搬历史成员 key。
- 区域划分、操作用途、深度决定分别确认。每次派发仍验证当前目标，不继承身份、检查结果、历史覆盖或重放权限。
- 来源撤销、条件或参数变化使派生决定重新待决，保留原决定和失效原因，不回退旧批准。上游新决定可恢复测试。
- hook、持久事件、SDK 和 HTTP 均已接入。hook 失败、超时或迟到不会自动批准；慢速人工或异步 LLM 可读取当前材料后再提交。

协议见[深度决定条件复用](../../EXPLORATION-DECISIONS.md#已确认区域的深度决定条件复用)。首版仅支持已确认区域；其他通用范围仍可提交新决定后恢复，跨文档深度复用继续开放。没有新增专用复用 UI 面板。

## OKX run-15

入口 `https://www.okx.com/convert/btc-to-usd`，目的页 `https://www.okx.com/markets/prices`。独立上层 `gpt-5.6-sol / low` 分批读取新材料，通过正式接口作判断；产品源码保持冻结，页面动作由引擎执行。

1. 关闭初始提示后，上游选取稳定的九成员导航容器，只将 Markets 纳入区域；分别批准当前用途和单样本深度，再注册该深度判断可复用。businessScope 仅为公开 UI 到达/返回巡检。
2. 首次 DFS 自动 Markets A→B，必要 Close 后用有当前 GET 历史证据的 history 返回 A。返回后产生新文档，旧区域和用途失效。动作数为 6。
3. 上游分别接受当前区域和用途复用。新探索组仍 pending / decisions=[]；不接受深度而运行 DFS，动作数保持 **6**，暂停 **REGION_REVIEW_REQUIRED**。存在唯一可复用候选不等于已接受。
4. DFS 入口先刷新观察，因此旧候选的 observationId、actionId 和 conditionKey 改变；语义条件及 memberKey 未变。守卫阻止提交旧接受命令，上游读取新材料后显式接受。当前派生 sample 使用新的成员 key，保留 reusedFrom，动作数仍为 6。
5. 再次 DFS 自动执行获批 Markets，B 只处理必要提示并按已有 skip 返回 A。最终动作数 **11**，没有第三次接受或 Markets 导航；入口页仍有待审内容。

11 次派发均返回 succeeded，但两次 Escape 没有关闭提示：首次返回后的 A 一次，第二次进入 B 后一次。对应观察的边界仍存在，后续原生 Close 才完成退出。两次 history 的 `stateRestored:false` 如实保留，不等于服务器或完整业务状态恢复。

两项上游修正完整留存：第 04 批把提交 sample 前的组版本用于后续注册，主流程在提交注册前拦下，第 05 批更正；第 08 批引用待决 DFS 前的候选，因正常观察刷新没有提交接受，第 09 批使用新候选。没有覆盖错误材料或把纠正前的提案当作已执行。

最终 **205 个当前控件未划分、15 个范围待决，整体 blocked / exhaustive:false**；结构扫描、Canvas、用途及其他未测范围仍存在。这里验证的是“程序收集与门控 → 上游决定 → 程序恢复”的有限闭环，不是整页穷尽。
